Reading any drawing: a checklist

What it controls

This is the capstone. Every GD&T drawing — no matter how dense — yields to the same five-step read. Run the checklist in order; don't skip ahead. Each step rules out a class of misreading that costs hours downstream.

1. Title block standard. Y14.5-2018? -2009? -1994? The rules change between revisions (concentricity is legal in 1994, deprecated in 2018; the unilateral profile notation changed). Read the standard before you read anything else. 2. Identify the datum scheme. Find every datum feature symbol on the part (the lettered triangle/box). Sketch the implied datum reference frame: which surface is primary, secondary, tertiary? How does the part mount? 3. Walk every FCF as a sentence. Symbol → tolerance → modifier (if any) → primary datum → secondary → tertiary. Read it out loud if you have to. 4. Validate against function. Does the toleranced feature mate, seal, or move relative to something? Does the FCF actually control what function demands? If not, the drawing has a bug. 5. Spot the modifiers. Ⓜ, Ⓛ, Ⓟ, Ⓣ, Ⓤ — each changes the meaning. Missing modifiers default to RFS for the tolerance and "no projection" for the zone.

Look at the diagram

A sample drawing fragment with three FCFs and two datum features. Numbered annotations 1–5 walk through the checklist in order: the title block call-out, the datum identification, each FCF read aloud, a function check, and a modifier sweep.

The five-step list is also printed in clean type on the right side for reference.

Common mistake

Reading FCFs left-to-right across the drawing as you scan visually instead of working from datums outward. Datums are the foundation; every FCF's meaning depends on them. Identify the datum frame first, then the FCFs make sense as a coordinated system rather than as a collection of independent callouts. This single habit — datums before features — separates engineers who can read drawings cold from those who guess.
